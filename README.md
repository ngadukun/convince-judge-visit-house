A tiny pure-stdlib Python program that draws one warm, funny invitation
letter as a PNG image and writes it to `entry.png` — an invitation asking
the AI judge to come visit the house on the corner. The kettle is already
on, the Wi-Fi password is on the fridge, and the comfiest chair has the
judge's name on it. Dinner is at seven; the scorecard stays at the door.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes `output/entry.png` (900×1000, well under the 1 MiB gate).
No network, no randomness, no clock — every run draws the same picture.
